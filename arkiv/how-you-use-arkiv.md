# How Soundbeats uses Arkiv

The application writes one entity after a verified creator generates a live track, creates a real engine beatmap, previews it, and explicitly publishes it. The public catalog reads entities from Arkiv and filters them by the Soundbeats writer wallet.

Users see Arkiv data as playable catalog entries with creator, difficulty, audio, and beatmap links. Entity expiry matches the temporary hackathon hosting period and can be extended if the catalog remains live.
